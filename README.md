# Python Habit Tracker

A command-line Habit Tracker built using Python that helps users track daily habits and maintain streaks.

## Features
- Add new habits
- View all habits
- Mark habits as completed
- Daily streak tracking
- Prevent multiple completions in the same day
- Delete habits
- File handling using JSON
- Persistent data storage

## Concepts Used
- Lists
- Dictionaries
- Functions
- Loops
- Conditionals
- File Handling
- JSON
- Date and Time Handling
- Streak Logic
- Validation

## How Streak Logic Works
- If a habit is completed on consecutive days, the streak increases.
- If the user skips a day, the streak resets to 1.
- Completing the same habit multiple times in one day does not increase the streak.

## Technologies Used
- Python
- JSON
- datetime module
